# ai-keiei-sanbo

Claude Codeを使って市場分析・競合分析・戦略設計・事業計画書作成を自動化するAI経営参謀プロジェクト。

---

## 成果物

| ファイル名パターン | 内容 |
|---|---|
| `事業検証レポート_〔事業名〕_〔日付〕.md` | 課題仮説・市場規模・競合調査・差別化ポイントの4項目 |
| `戦略設計_〔事業名〕_〔日付〕.md` | PEST分析・SWOT分析・3C分析 |
| `事業計画書_〔事業名〕_草案_〔日付〕.md` | 7章構成の事業計画書草案 |

---

## 技術スタック

| 項目 | 内容 |
|---|---|
| 生成ツール | Claude Code |
| 出力形式 | Markdown |
| バージョン管理 | GitHub |

---

## 使い方

1. Claude Codeを起動してこのプロジェクトフォルダを開く
2. 各ドキュメントのプロンプトを入力して生成を実行する
3. 生成されたファイルをGitHubにプッシュしてバージョン管理する

プロンプト例は `CLAUDE.md` を参照。
